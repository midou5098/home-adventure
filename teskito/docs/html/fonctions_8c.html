Draw one tiled background layer.

The function repeats the same texture horizontally so the layer never leaves blank space while the camera scrolls. The y and h parameters are the values you tune from the macros in headers.h.

Parameters
rendererSDL renderer.
textureLayer texture.
viewportArea where the layer is drawn.
scrollHorizontal scroll value for this layer.

hDrawn height of the layer.

Check whether the player lands on top of a platform this frame.

The previous bottom position prevents side collisions from being treated as landings. Only a downward crossing from above counts as standing on the platform.

Parameters
playerPlayer after movement.
platformPlatform to test.
previous_bottomPlayer bottom before vertical movement.
Returns
