# Space Invaders

A small `Space Invaders` clone written in C with SDL2.

## Build

```sh
make
```

## Run

```sh
make run
```

## Controls

- `Left` / `A`: move left
- `Right` / `D`: move right
- `Space`: shoot
- `Esc`: quit

The window title shows score, lives, and state. On loss or victory, the game draws a styled popup inside the same window with a single `Quit` button.
