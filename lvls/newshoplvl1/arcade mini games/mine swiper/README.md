# SDL2 Minesweeper

Small Minesweeper clone written in C with SDL2 only.

Current setup: `10x10` board with `15` mines.

## Build

```bash
make
```

## Run

```bash
./minesweeper
```

## Controls

- Left click: reveal a tile
- Right click: place or remove a flag
- Arrow keys / `WASD` / `HJKL`: move the keyboard cursor
- `Space` or `Enter`: reveal the selected tile
- `F`: place or remove a flag on the selected tile
- `I`: show or hide the game rules
- After win/loss: click `QUIT` or press `Enter`, `Space`, `Q`, or `Esc`
